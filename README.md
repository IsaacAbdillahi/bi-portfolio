# 📁 Projects

## ⚙️ Operations & SLA Performance Analysis

**Google BigQuery | SQL | Power BI**

End-to-end Business Intelligence project analysing operational case performance within a simulated financial services Operations department.

The project investigates where SLA breaches are occurring, the scale and age of the operational backlog, and which areas management should prioritise to improve performance.

### Key Outcomes

- Profiled **50,075 raw records representing 50,000 unique operational cases**
- Built a reproducible SQL cleaning and transformation pipeline in **Google BigQuery**
- Identified **11,207 SLA breaches** across 43,418 completed cases
- Calculated an overall SLA breach rate of approximately **25.81%**
- Identified **6,582 active backlog cases**
- Found **5,913 cases aged over 60 days**, representing approximately **89.84% of the active backlog**
- Identified **1,622 High/Urgent cases** already aged over 60 days
- Analysed SLA performance by team, priority, case type, escalation and reopened status
- Built an analysis-ready reporting layer for Power BI
- Developed a **four-page interactive Power BI dashboard**
- Produced management recommendations based on backlog volume and SLA risk

### Skills Demonstrated

`SQL` `BigQuery` `Data Cleaning` `CTEs` `CASE` `Data Quality` `DAX` `Power BI` `KPI Reporting` `Business Analysis`
